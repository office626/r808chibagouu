# MVP範囲

## MVP定義

### 目的

入口が二つに分かれたサイトとして、支援者が行政情報の収集を分担でき、県民が初日ログ対象市町村の被害ログといまの支援策を見られることを確かめる。

### 対象ユーザー

- 支援者：CTZCメンバー
- 県民：初日ログ対象の住民（警戒レベル5が出た自治体および流山市。枠は全市町村）

### 成功の定義

- トップで県民と支援者が迷わず分かれる
- 運営者以外から、許可リストや誤りの指摘、またはアイデアが出る
- 初日ログ対象に、行政または報道の出典付きログが自動更新で載っている
- 最終取得日時が1日以内である（ジョブが動いている）

## スコープ

### MVP に含める ✅

| 機能 | 理由 |
|------|------|
| トップの二つの入口 | 両面を持つサイトの約束 |
| 支援者ホーム、Slack、意見箱、やること一覧 | 情報共有と参加の最小構成 |
| 行政情報の収集を募集項目にする | 許可リストと例外対応。全件手入力は主経路にしない |
| 県民ホーム、市町村一覧、全市町村のページ枠 | 県全域を対象にする |
| 被害状況ログ（時系列、上書きしない） | 県民向けの過去ログと現在 |
| 行政・報道の1日1回自動収集と再公開 | 人手に依存せず情報を更新する |
| 出典区分（行政／報道）と最終取得日時 | 信頼と鮮度 |
| いま受けられる支援策（受付状態付き） | 生活支援へ移った問い合わせに応える。状態は行政を優先 |
| 生活再建の段取り（共通の型） | 罹災証明の前後、修理か仮設か |
| 県全域の支援策ページ | 共通制度を複製しない |
| 最終更新日と有志運営の明示 | 信頼と鮮度 |

### MVP に含めない ❌

| 機能 | 理由 | 対応時期 |
|------|------|----------|
| 全市町村のログ・制度の完備 | 1名では不可能 | Phase 2 |
| QA型ナビゲーター | 制度データが先 | Phase 2 |
| いまのフェーズの全市町村自動判定 | 公式確認が前提 | Phase 2 |
| ユーザー登録・ログイン | 閲覧のみなら不要 | Phase 2 |
| サイト上での投稿・編集 | シートで代替 | Phase 2 |
| 地図ダッシュボード | データ整備が前提 | Phase 3 |
| 多言語対応 | 優先度が低い | 将来検討 |
| 罹災調査システムそのもの | 行政の領域（能登のタブレット等） | 対象外 |

## タイムライン（目安）

| フェーズ | 時期 | 内容 |
|----------|------|------|
| MVP | 即時 | 二入口。支援者の場。県民側は枠＋レベル5対象および流山市のログと支援策 |
| Phase 2 | 〜1ヶ月 | 市町村を分担して埋める。QAナビ。フェーズ表示 |
| Phase 3 | 状況次第 | 地図など追加の見える化 |

## 制約事項

| 制約 | 内容 |
|------|------|
| 人的リソース | 現在1名 |
| 予算 | なし |
| 時間 | 速度が最優先 |
| 情報の正確性 | ログは出典 URL 必須。行政と報道を区別。制度の受付状態は行政を優先。全文転載しない |
| シート運用 | [運用スプレッドシート](https://docs.google.com/spreadsheets/d/1_dHZHMLvTx6iTCzwvbw6U9cTHjTIH_6RlEob81Ng7KM/edit?usp=sharing)。閲覧はリンクを知っている人。編集は所有者 `tutti666@gmail.com` が招待 |
| 更新頻度 | 毎日 6:00 JST。失敗時は前回データを維持 |
| 市町村数 | 枠は全市町村。中身は分担 |

## リスクと対策

| リスク | 対策 |
|--------|------|
| 二つの面が混ざって県民が迷う | 入口と主ボタンを分ける。受け入れ条件で担保する |
| 未確認の現地報告を事実として出す | 出典 URL がある件だけ公開する。SNS の伝聞は自動収集の対象にしない |
| 自動収集が止まる・誤る | 前回データを残す。最終取得日時を出す。支援者面で障害を共有する |
| 報道の著作権 | 全文転載しない。許可リストのフィードを優先する |
| 行政と報道が食い違う | 制度・受付状態は行政を優先し、報道はログに「報道による」と出す |
| 運営1名が息切れする | 本文更新は自動。人手は許可リストと例外 |
| 全市町村が空 | 初日対象を厚く取る。他は枠＋公式リンク |
| 袖ケ浦と重複する | 作成後にソース再利用を確認する。公開事例へのリンクは可 |
