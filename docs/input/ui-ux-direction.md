# UI/UX方針

## 1. 全体の方向性

### デザインテーマ

**実用一辺倒。** 加えて、開いた瞬間に「自分はどちらの入口か」が分かる。

### キーワード

- 入口が二つ
- シンプル
- 読みやすい
- スマホ最優先
- 軽い
- 信頼できる
- 履歴が残る

### 参考サービス

| サービス | 参考にする点 |
|----------|--------------|
| 東京都 新型コロナウイルス感染症対策サイト | 情報密度とオープンな運営の見せ方 |
| [熊本豪雨2020情報サイト](https://www.itmedia.co.jp/news/articles/2007/07/news067.html) | スマホでの割り切り |
| [災害支援ナビゲーター（シビックテック袖ケ浦）](https://civictechsodegaura.org/archives/587) | QAで制度を絞る体験 |

## 2. ビジュアル

### カラー方針

- 背景：白または極薄いグレー
- テキスト：十分なコントラスト
- 入口：県民向けと支援者向けで、ラベルと短い説明で区別する。色だけに頼らない
- 支援策の受付状態：受付中／準備中／終了を色と文字の両方で示す
- やることのステータス：募集中／進行中／完了も同様

**[仮]** 具体的な色は未定。CTZCのブランドカラーがあれば合わせる。

### タイポグラフィ方針

本文は大きめ。見出しと本文の差をはっきりつける。装飾的なフォントは使わない。

### アイコン・イラスト

最小限。入口の区別に簡単なアイコンを使ってもよいが、それだけで意味が分からない状態は避ける。

## 3. UX原則

### 重視する体験

1. **最初に入口が分かれる** — 県民が Slack に、支援者が申請手続きに、迷い込まない
2. **開いた瞬間に何のサイトか分かる**
3. **通信が悪くても開く**
4. **県民には「いま」と「これまで」が見える** — 最新とログ
5. **情報の出どころが分かる**

### 避けたいUX

1. 重い
2. 公式に見えてしまう
3. いつの情報か分からない
4. 入口が一つのメニューに全部並んでいる
5. 空っぽに見える
6. 県民面でボランティア募集が一番目立つ

## 4. 画面構成

### 主要画面一覧

| 画面名 | 面 | 目的 | 主要要素 |
|--------|----|------|----------|
| トップ（入口） | 共通 | どちら向きか選ぶ | 県民／支援者の二つの大きな入口、一行のサイト説明、最終更新日 |
| 県民向けホーム | 県民 | 自分の市へ進む | 市町村から探す、県の支援策、公式リンク |
| 市町村一覧 | 県民 | 自治体を選ぶ | 全市町村。準備中でも選べる |
| 市町村ページ | 県民 | いまとこれまで | フェーズ、いまの支援策、被害ログ、生活再建の段取り、公式リンク |
| 県全域の支援策 | 県民 | 県の制度 | 制度カード |
| 支援者向けホーム | 支援者 | 参加する | 役割説明、Slack、やること一覧への導線、意見箱 |
| やること一覧 | 支援者 | 手を挙げる | ステータス、担当者、対象市町村 |
| 意見箱 | 支援者 | Slack 外の声 | 申請窓口ではない旨 |
| 支援制度ナビ | 県民（Phase 2） | 質問で絞る | 袖ケ浦と同じ QA 型 |

### 画面遷移図

```
                         [トップ：二つの入口]
                        /                    \
                       /                      \
        [県民向けホーム]                      [支援者向けホーム]
         /      |                              /       |      \
        v       v                             v        v       v
 [市町村ページ] [県の支援策]            [やること一覧] [Slack] [意見箱]
  いま / ログ / 段取り
```

ヘッダーは、今いる面の中の移動を主にする。もう一方の面は「県民の方はこちら／協力する方はこちら」を小さく置く。

## 5. インタラクション

### アニメーション方針

使わない。

### フィードバック

意見箱の送信結果が分かること。ログの「最新」がいつか分かること。

### エラー表示

シート読み込み失敗時は白紙にせず、公式サイトへ行くリンクを残す。

## 6. 明記すべき事項

両面のフッターに次を置く。

- CivicTechZenChiba（CTZC）の有志運営であり、行政の公式発表ではないこと
- 最新かつ正確な情報は千葉県および各市町村の公式サイトで確認すること
- 支援制度の適用可否は各実施機関の判断であること
- 申請・問い合わせは本サイトではなく公式窓口へ
- 災害支援ナビゲーターの先行実装は [シビックテック袖ケ浦](https://civictechsodegaura.org/) によること
- 現地の行政プロセスに関する知見はシビックテックもばら（篠田さん）の報告を参考にしたこと（掲載許諾を確認）
- 運営への連絡（支援者面の Slack または意見箱）
