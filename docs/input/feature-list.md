## 機能詳細

### 二つの入口

**概要：** 県民向けの見える化と、支援者向けの情報共有を、同じサイトに持ちつつ画面を混線させない。

**ユーザーストーリー：**
「被災した住民として、ボランティア募集や Slack ではなく、自分の市の被害と支援策だけを見たい」
「協力したい有志として、県民向けの手続き案内ではなく、今人手の要る収集作業を見たい」

**受け入れ条件：**

- [ ] トップに入口が二つあり、役割が一文で分かる
- [ ] 県民面の主ボタンに Slack 参加がない
- [ ] 支援者面の主ボタンに罹災証明の申請案内がない
- [ ] もう一方の入口へはフッター等から戻れる

---

### 被害状況ログ

**概要：** 公式発表の履歴。最新だけでなく過去を残す。

**ユーザーストーリー：**
「茂原市民として、節水制限がいつ始まり、住宅被害の発表がどう推移したかを後から辿りたい。なぜなら公式サイトは最新だけになり、経緯が消えるから」

**受け入れ条件：**

- [ ] 同一市町村に複数件のログが時系列で残る
- [ ] 各件に日時と公式URLがある
- [ ] 最新件がページ上部の「いま」と一致する
- [ ] 未確認の伝聞は公開しない（篠田さん報告は公式確認後に載せる）

---

### いま受けられる支援策と生活再建の段取り

**概要：** 袖ケ浦の制度ナビを県全域へ広げ、篠田さんが示した生活再建の流れ（罹災証明の前後、修理か仮設か）を載せる。

**ユーザーストーリー：**
「床上浸水した住民として、いま窓口に聞くべきなのが避難所なのか罹災証明なのか、修理と仮設のどちらを後で選ぶことになるのかを先に知りたい」

**受け入れ条件：**

- [ ] 受付中／準備中／終了が分かれている
- [ ] 段取りの図または箇条書きがある
- [ ] 金額・所要日数は公式確認済みのときだけ出す
- [ ] 「適用可否は各機関の判断」と表示する

---

### アイデア／やること一覧（支援者）

**概要：** 有志が行政情報の収集を分担する場。

**ユーザーストーリー：**
「CTZCメンバーとして、○○市の公式発表をログに載せる仕事が空いているのを見て手を挙げたい」

**データ項目：**

| 項目 | 内容 | 必須 |
|------|------|------|
| タイトル | やることの名前 | ○ |
| 説明 | | ○ |
| ステータス | 募集中／進行中／完了 | ○ |
| 担当者 | | |
| 対象市町村 | 収集タスクの場合 | |
| 登録日 | | ○ |

**受け入れ条件：**

- [ ] シートの内容が一覧になる
- [ ] 公開時に「行政情報の収集」系の募集が1件以上ある
- [ ] 0件のとき参加を促す文言がある
