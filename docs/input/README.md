# CTZC 千葉豪雨 復興支援ポータル（仮称）

## 概要

令和8年8月の千葉豪雨を受けた、CivicTechZenChiba（CTZC）のポータル。**入口を二つに分ける。**

1. **県民向け（状況の見える化）** — 被害状況の時系列ログと、いま受けられる支援策の一覧
2. **支援者向け（情報共有・協働）** — 有志が集まり、行政情報の収集と伝達拡散を分担する場

県民向けの中身は、[シビックテック袖ケ浦の災害支援ナビゲーター](https://civictechsodegaura.org/archives/587) を県全域・市町村別に広げることと、シビックテックもばら篠田さんからの状況報告（生活再建の段取りと行政情報の迅速な伝達）を土台にする。

## 解決する課題

支援したい人の意思が Slack で流れて消える。一方、被災した県民は、公式発表が上書きされて過去の被害経過が追えず、いま自分の市町村で何の制度が動いているかも分かりにくい。問い合わせの中心は避難から生活再建へ移るが、罹災証明書の交付まで時間がかかり、次に何をすればよいかが見えない。

シビックテックにできることの中心は、**行政情報の速やかな収集と伝達拡散**である（篠田さん）。

## ターゲットユーザー

**県民向け：** 千葉県民・被災者（自分の市町村の状況と支援策を見たい人）
**支援者向け：** CTZCメンバーおよび「千葉のために何かしたい」有志

MVPでは、支援者側の場を動かしつつ、県民側は全市町村の枠＋優先市町村（まず茂原市）のログと支援策を出す。

## 主要機能

**共通**

- トップで「県民の方」「支援・協働する方」が迷わず分かれる入口

**県民向け**

- 市町村ごとの被害状況ログ（過去〜現在。公式発表の時系列）
- いま受けられる支援策の一覧（国・県・市町村。いま受付中のものを優先表示）
- 生活再建の段取り（罹災証明 → 応急修理か応急仮設かの分岐）
- 公式災害情報へのリンク

**支援者向け**

- Slack 参加、アイデア／やること一覧、意見箱
- 行政情報の収集・確認・県民向けページへの反映を分担する募集
