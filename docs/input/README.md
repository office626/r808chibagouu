# CTZC 千葉豪雨 復興支援ポータル（仮称）

## 概要

令和8年8月の千葉豪雨を受けた、CivicTechZenChiba（CTZC）のポータル。**入口を二つに分ける。**

1. **県民向け（状況の見える化）** — 被害状況の時系列ログと、いま受けられる支援策の一覧
2. **支援者向け（情報共有・協働）** — 有志が集まり、自動収集の許可リストや誤りの訂正、伝達拡散を分担する場

県民向けの中身は、[シビックテック袖ケ浦の災害支援ナビゲーター](https://civictechsodegaura.org/archives/587) を県全域・市町村別に広げることと、とある行政における生活再建の段取り・行政情報の伝達に関する知見を土台にする。袖ケ浦のソース再利用は、作成後に確認する。

## 解決する課題

支援したい人の意思が Slack で流れて消える。一方、被災した県民は、公式発表が上書きされて過去の被害経過が追えず、いま自分の市町村で何の制度が動いているかも分かりにくい。問い合わせの中心は避難から生活再建へ移るが、罹災証明書の交付まで時間がかかり、次に何をすればよいかが見えない。

シビックテックにできることの中心は、**行政・報道の公開情報を集め、履歴付きで届けること**である。収集自体は1日1回自動で行い、人は許可リストと例外に回る。

## ターゲットユーザー

**県民向け：** 千葉県民・被災者（自分の市町村の状況と支援策を見たい人）
**支援者向け：** CTZCメンバーおよび「千葉のために何かしたい」有志

MVPでは、支援者側の場を動かしつつ、県民側は全市町村の枠を出し、初日のログは警戒レベル5（大雨特別警報）が出た自治体と流山市から埋める。

## 主要機能

**共通**

- トップで「県民の方」「支援・協働する方」が迷わず分かれる入口

**県民向け**

- 市町村ごとの被害状況ログ（過去〜現在。行政・報道を1日1回自動収集）
- いま受けられる支援策の一覧（受付状態は行政を優先）
- 生活再建の段取り（罹災証明 → 応急修理か応急仮設かの分岐）
- 公式災害情報へのリンク

**支援者向け**

- Slack 参加、アイデア／やること一覧、意見箱
- 収集先の許可リスト整備、誤りの指摘、自動更新停止時の対応

## 注意

本ドキュメントは対話から起こした初版です。`[仮]` が付いた項目は仮置きです。とある行政の説明に基づく制度名・金額・所要日数は、**公開前に各市町村の公式発表で裏取りする。** 金額や日数をサイト上で断定しない。個人名・特定自治体の内部情報は公開資料に載せない。
