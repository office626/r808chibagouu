# ターゲットユーザー

サイトは最初から二つの利用者を想定する。トップの入口で分ける。

**県民向け：** 千葉県民・被災者
**支援者向け：** CTZCメンバーおよび外部の有志

MVPの中身は、支援者側を先に動かし、県民側は全市町村の枠と、初日ログ対象（警戒レベル5が出た自治体および流山市）から埋める。

## 県民向け：千葉県民・被災者

### 基本情報

- 名前（仮）：鈴木さん
- 属性：被災地域の住民。年齢層は幅広く、高齢者を含む
- 利用環境：スマートフォン。通信環境が不安定な可能性がある

### 課題・ペイン

1. 公式サイトは最新情報に上書きされ、昨日までの被害や節水制限の経緯が追えない
2. 国・県・市町村の支援策が分散し、「いま自分の市町村で受けられるもの」が分からない
3. 問い合わせの中心が避難から生活再建へ移っても、罹災証明の前に何をすればよいか分からない
4. 転居が必要な場合、仮設（家賃補助）と住宅の応急修理のどちらを選ぶかの説明が、自分の自治体の進行状況と結びついていない

### 現在の解決方法

市町村の公式サイトを探す。親族や近所に聞く。窓口に電話する。制度があること自体を知らない場合もある。

### 求めているもの

- 自分の市町村の、被害状況の過去ログと現在
- いま受けられる支援策の一覧と、これから始まる手続き
- 生活再建の段取り（罹災証明の前後で何が変わるか）
- 公式の申請先へのリンク

### このプロダクトを使う瞬間

自宅や避難先で状況を確認したいとき。生活再建の手続きを調べ始めたとき。ニュースやSNSでサイトを知ったとき。

### 注意点

制度の本文・金額・日数を独自に断定しない。適用可否は各機関の判断である旨を明示する。とある行政の説明に基づく数字は、各市町村の公式確認後にのみ掲載する。個人名・特定の内部情報は出さない。

## 支援者向けメイン：CTZCメンバー

### 基本情報

- 名前（仮）：佐藤さん
- 属性：千葉県在住・在勤の会社員エンジニア、またはデザイナー
- CTZCとの関係：Slackに参加しており、イベントには時々顔を出す

### 課題・ペイン

豪雨のニュースを見て「自分の技術で何かできないか」と思っているが、次で止まっている。

1. 何が必要とされているのか分からない
2. 勝手に動いていいのか、誰と組めばいいのか分からない
3. Slackを開いても会話が流れていて、今の全体像がつかめない

### 現在の解決方法

Slackを眺めている。個人的に情報を集めている。あるいは、何もできていない。

### 求めているもの

行政情報の収集と県民向けページへの反映など、「これをやります」と手を挙げられる受け皿。

### このプロダクトを使う瞬間

仕事終わりや週末。手が空いていて、何かしたいと思ったとき。

## 支援者向けサブ：外部の有志

### 基本情報

- 名前（仮）：田中さん
- 属性：千葉県出身または在住。技術者とは限らない
- CTZCとの関係：知らない。SNSや知人経由でサイトを知る

### 課題・ペイン

寄付以外に何かしたいが、現地ボランティアは難しい。オンラインでできる貢献の入口が見つからない。

### 求めているもの

- 何をやっている団体なのかが一目で分かる説明
- 「自分の市町村の公式発表を拾ってログに載せる」など、技術がなくてもできる分担
- Slack の入り口

### このプロダクトを使う瞬間

SNSでサイトのリンクを見かけたとき。滞在時間は短く、県民入口と支援者入口が混ざっていると離脱する。

## 非ターゲット

- 千葉県外の災害に関する情報を求める人（能登版など他地域ナビへのリンクは可）
- 現地での物理的なボランティア活動のマッチングを求める人（社協の災害ボランティアセンターが担う領域）
- 報道機関向けの詳細な被害統計を求める人
- 罹災証明の調査そのもの（行政のタブレット調査システムの領域。CTZCは導入を待って情報を伝える側）
